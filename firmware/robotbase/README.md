# 机器人底盘控制板通信协议

## 基本信息
- 串口通信波特率：115200
- 命令行结束符：换行符（\n）
- 通信编码：ASCII

## 轮子与轴映射（XYZA）

本项目在麦克纳姆模式下使用 `X/Y/Z/A` 四个线性轴分别驱动四个轮子，默认对应关系如下：

| 轴 | 轮子位置 |
|----|----------|
| X  | 右前轮（Front Right） |
| Y  | 左前轮（Front Left） |
| Z  | 右后轮（Rear Right） |
| A/E1  | 左后轮（Rear Left） |

> 说明：上表与当前固件中的运动符号约定一致（例如前进为 `X- Y+ Z- A+`）。

## 命令确认机制
- 所有命令发送后，底盘控制板会立即回复"ACK"确认
- 若未收到ACK，上位机应重新发送命令

## 状态反馈机制
- 控制板通过命令查询获取系统状态
- 命令：`STATUS`
- 返回格式：`STATUS:stepflage=X,isSerialControlled=X,isDistanceControlled=X,currentSpeed=X,isRaytracingEnabled=X,isCentered=X`
- 各参数含义：
  - stepflage: 运动标志（0=停止，1=运动中）
  - isSerialControlled: 串口控制模式（0=否，1=是）
  - isDistanceControlled: 距离控制模式（0=否，1=是）
  - currentSpeed: 当前运动速度（mm/s）
  - isRaytracingEnabled: 光线追踪功能（0=关闭，1=开启）
  - isCentered: 是否居中（0=否，1=是）

## 命令格式

### 基础运动命令
| 命令 | 功能 | 示例 |
|------|------|------|
| F | 以默认速度（50 mm/s）前进 | F |
| B[速度] | 后退 | B100（以100 mm/s速度后退） |
| L[速度] | 左转 | L75（以75 mm/s速度左转） |
| R[速度] | 右转 | R50（以50 mm/s速度右转） |
| SL[速度] | 左平移 | SL30（以30 mm/s速度左平移） |
| SR[速度] | 右平移 | SR40（以40 mm/s速度右平移） |

### 距离控制命令
| 命令 | 功能 | 示例 |
|------|------|------|
| FD[距离] | 以默认速度（50 mm/s）前进指定距离 | FD50（前进50 mm） |
| BD[距离]:[速度] | 后退指定距离和速度 | BD100:60（以60 mm/s速度后退100 mm） |
| SDL[距离] | 以默认速度（50 mm/s）左平移指定距离 | SDL50（左平移50 mm） |
| SDR[距离]:[速度] | 右平移指定距离和速度 | SDR100:60（以60 mm/s速度右平移100 mm） |
| LD[角度] | 以默认速度（50 mm/s）左转指定角度 | LD90（左转90度） |
| RD[角度]:[速度] | 右转指定角度和速度 | RD180:70（以70 mm/s速度右转180度） |

### 特殊命令
| 命令 | 功能 | 优先级 |
|------|------|--------|
| S | 立即停止所有运动 | 最高优先级 |

### 光线追踪命令
- 光线追踪默认开启
| 命令 | 功能 |
|------|------|
| FINDRAY | 开启光线追踪功能，机器人不随激光移动 |
| DISABLERAY | 关闭光线追踪功能，机器人随激光移动 |

## 参数限制
- **速度范围**：0-200 mm/s（超出范围会自动限制）
- **距离范围**：0-10000 mm（超出范围会自动限制）
- **角度范围**：0-360度

## 参数验证
- 无效参数（如负数、非数字）会使用默认值
- 超出范围的参数会被限制在有效范围内
- 系统会通过串口返回参数调整的警告信息

## 注意事项
- 所有命令必须以换行符结尾
- 速度和距离参数支持小数
- 停止命令（S）具有最高优先级，可中断任何正在执行的命令
- 横向光线追踪移动算法仍在调试中，建议使用固定距离命令（SDL/SDR）进行演示
