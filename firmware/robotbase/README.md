# 机器人底盘控制板通信协议

## 基本信息
- 串口通信波特率：115200
- 命令行结束符：换行符（\n）
- 通信编码：ASCII

## 轮子与轴映射（XYZA）

本项目在麦克纳姆模式下使用 `X/Y/Z/A` 四个线性轴分别驱动四个轮子，默认对应关系如下：

| 轴 | 轮子位置 |
|----|----------|
| X  | 右前轮（Front Right） |
| Y  | 左前轮（Front Left） |
| Z  | 右后轮（Rear Right） |
| A/E1  | 左后轮（Rear Left） |

> 说明：上表与当前固件中的运动符号约定一致（例如前进为 `X- Y+ Z- A+`）。

## 命令确认机制
- 所有命令发送后，底盘控制板会立即回复"ACK"确认
- 若未收到ACK，上位机应重新发送命令

## 状态反馈机制
- 控制板通过命令查询获取系统状态
- 命令：`STATUS`
- 返回格式：`STATUS:stepflage=X,isSerialControlled=X,isDistanceControlled=X,currentSpeed=X,isRaytracingEnabled=X,isCentered=X`
- 各参数含义：
  - stepflage: 运动标志（0=停止，1=运动中）
  - isSerialControlled: 串口控制模式（0=否，1=是）
  - isDistanceControlled: 距离控制模式（0=否，1=是）
  - currentSpeed: 当前运动速度（mm/s）
  - isRaytracingEnabled: 光线追踪功能（0=关闭，1=开启）
  - isCentered: 是否居中（0=否，1=是）

## 命令格式

### 基础运动命令
| 命令 | 功能 | 示例 |
|------|------|------|
| F[速度] | 前进（速度可选，缺省50） | F / F100 |
| B[速度] | 后退（速度可选，缺省50） | B / B100 |
| L[速度] | 左转（速度可选，缺省50） | L / L75 |
| R[速度] | 右转（速度可选，缺省50） | R / R50 |
| SL[速度] | 左平移（速度可选，缺省50） | SL / SL30 |
| SR[速度] | 右平移（速度可选，缺省50） | SR / SR40 |

### 距离控制命令
| 命令 | 功能 | 示例 |
|------|------|------|
| FD[距离][:速度] | 前进指定距离，速度可选 | FD50 / FD50:80 |
| BD[距离][:速度] | 后退指定距离，速度可选 | BD100 / BD100:60 |
| SDL[距离][:速度] | 左平移指定距离，速度可选 | SDL50 / SDL50:70 |
| SDR[距离][:速度] | 右平移指定距离，速度可选 | SDR100 / SDR100:60 |
| LD[角度][:速度] | 左转指定角度，速度可选 | LD90 / LD90:55 |
| RD[角度][:速度] | 右转指定角度，速度可选 | RD180 / RD180:70 |

### 特殊命令
| 命令 | 功能 | 优先级 |
|------|------|--------|
| S | 立即停止所有运动 | 最高优先级 |

### 光线追踪命令
- 光线追踪默认开启
| 命令 | 功能 |
|------|------|
| FINDRAY | 开启光线追踪功能，机器人不随激光移动 |
| DISABLERAY | 关闭光线追踪功能，机器人随激光移动 |

## 参数限制
- **速度范围**：0-200 mm/s（超出范围会自动限制）
- **距离范围**：0-10000 mm（超出范围会自动限制）
- **角度范围**：0-360度

## 参数验证
- 无效参数（如负数、非数字）会使用默认值
- 超出范围的参数会被限制在有效范围内
- 系统会通过串口返回参数调整的警告信息
- 连续运动命令（F/B/L/R/SL/SR）再次下发时，会立即按新速度重启该运动

- 所有命令必须以换行符结尾
- 速度和距离参数支持小数
- 停止命令（S）具有最高优先级，可中断任何正在执行的命令
- 横向光线追踪移动算法仍在调试中，建议使用固定距离命令（SDL/SDR）进行演示
